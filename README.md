# 청년 주거 혜택 한눈에 보기

엑셀의 `청년 주택 공고` 시트를 읽어 만든 React·TypeScript 웹 앱입니다. Vite, Tailwind CSS, lucide-react를 사용합니다.

## 로컬 실행

Node.js 22.12 이상과 npm을 준비한 뒤 이 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

## 엑셀 갱신

프로젝트 폴더의 `youth_housing_data.xlsx`를 수정하고 저장한 다음 실행합니다.

```sh
npm run convert
```

다른 위치의 엑셀 원본을 계속 관리한다면 경로를 직접 지정할 수 있습니다.

```powershell
npm run convert -- "C:\Users\조예빈\Desktop\AI와 언어학\youth_housing_data.xlsx"
```

스크립트는 첫 행에서 지정된 10개 열을 이름으로 찾고 완전히 빈 행을 건너뜁니다. 날짜는 연-월-일 형식으로 정규화하며, 잘못된 날짜나 누락된 열이 있으면 해당 위치를 알려줍니다. 변환이 성공하면 `src/data/notices.json`이 교체됩니다. 개발 서버에서는 변경 내용이 곧바로 반영됩니다.

## LH API로 갱신

프로젝트 루트의 `.env`에 `LH_API_KEY`를 설정한 뒤 `npm run fetch-lh`를 실행합니다. 한국 날짜 기준 최근 두 달 동안 게시된 공고를 페이지별로 조회하고, 제목이나 유형에 청년·기숙사·행복주택·전세임대가 포함된 목록으로 `src/data/notices.json`을 교체합니다. 마감된 공고도 포함합니다. 자격과 서류는 공식 공고문에서 확인할 항목을 안내합니다. 엑셀 데이터로 돌아가려면 `npm run convert`를 실행하세요.

## 빌드

```sh
npm run build
npm run preview
```

빌드 명령은 TypeScript를 검사한 뒤 정적 웹 파일을 `dist/`에 생성합니다. 엑셀을 갱신한 뒤 배포용 파일에도 반영하려면 다시 빌드하세요.

## 화면의 날짜와 체크리스트

- 헤더의 기준일은 엑셀에 기록된 가장 최근 기준일입니다.
- D-Day는 한국 시간의 오늘 날짜를 기준으로 계산합니다. 당일은 D-Day이며, 종료된 공고는 목록 뒤에 표시합니다.
- 상시모집의 개별 종료 시각과 조기 종료 조건은 세부 안내에서 확인할 수 있습니다.
- 준비물 체크 상태는 현재 브라우저에 공고별로 저장됩니다. 초기화는 선택한 공고에만 적용됩니다.
